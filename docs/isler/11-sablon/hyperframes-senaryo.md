# HyperFrames: senaryo

Anatomi: Hook → Giriş → Gövde → CTA. İlk kareden başlık (şablon değişikliği bu videoyla başlar).

Kaynak: https://github.com/heygen-com/hyperframes (README ve GitHub API, 2026-11-02: 77.557 yıldız, Apache-2.0, Node 22+ ve FFmpeg gerekir; istem örneği README'den uyarlandı). Bu video gerçekten HyperFrames ile render edilir (`npx hyperframes@0.8.158`). "Tek cümleyle video" denmez: sınır sahnesi birkaç tur düzeltmeyi söyler; Claude Code ücretli olduğu için bütün akışa "ücretsiz" denmez.
